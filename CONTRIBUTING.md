# Contributing

Thanks for helping keep this list useful and honest.

## What belongs here

**Agentic AI security** — systems where LLMs **act** (tools, code, APIs, money, data). Not generic ML security unless it directly applies to agents.

Good fits:

- Runtime / gateway enforcement (policy on tool calls)
- MCP and tool-protocol security
- Red team, eval, and benchmarks for agents
- Papers and roadmaps (AI control, agent safety at the action boundary)
- Standards and guides (OWASP, vendor hardening)

## What we skip

- Pure prompt-tip lists with no enforcement story
- Duplicate entries already covered better in [awesome-mcp-security](https://github.com/Puliczek/awesome-mcp-security) unless agent-wide context matters
- Marketing pages with no technical substance
- Broken or abandoned projects (unless historically important — mark as archived)

## How to submit

1. Open a PR with **one section** change when possible.
2. Add the link in **alphabetical order** within that section.
3. One-line description: what it does + why it matters for agents.
4. Disclose if you are the author/maintainer.

## Style

- Use `[name](url) — description` format.
- Prefer primary repos and official docs over blog spam.
- No affiliate links.

Maintainers may edit wording for consistency. We reserve the right to reject low-signal PRs.
